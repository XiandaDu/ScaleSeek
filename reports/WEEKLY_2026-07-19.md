# 周总结（2026-07-11 → 07-19）：主表全铺 + 从"有数"到"数可信"

## 背景与动机

上周（07-04→07-10）的成果是把评测体系和 baseline 忠实性搭起来，但结果只覆盖
**popqa 一个数据集**（外加 hotpotqa 半张表）。"主流 retriever agent vs DCI 类"这条
主轴，当时并没有跨数据集的证据。

本周的目标就是把这张表铺满，并回答一个更难的问题：**这些数字经得起推敲吗？**
后一半占了本周大部分时间——本周有三次"跑完了但数据是假的/不可用"的事故，
每一次都指向同一类问题：**成功信号不等于有效结果**。

期间可用算力剧烈波动：octal30 宕机后复活、octal35 CUDA 故障、octal40/41 被他人整机占用、
abaque01 驱动损坏。全程在 4 种不同架构的 GPU（L40S sm_89 / A5000 sm_86 / 3090 sm_86 /
2080Ti sm_75）之间迁移作业，每种都有各自的显存与并行坑。

## 本周三次事故：成功信号 ≠ 有效结果

这是本周最重要的方法论收获，三次形态完全不同，但根子是同一个。

**① 服务没起来，评测照样"跑完"（job 7159，10 格假数据）**
octal40/41 缺 `/usr/local/cuda` 且未设 `CUDA_HOME` → flashinfer JIT 找不到 nvcc →
vLLM 全灭。但 `run_eval` 照跑，每行 `api_error`，`compute_metrics` 照样写出 EM=0.0
的 metrics.json，作业照样打印 `ALL_DONE`——而那个 metrics.json 又会被
`[ -f … ] && skip` 守卫当成"已完成"，**永久掩盖**。
→ 加了两道闸：`waitp` 端口不通就放弃整条 lane（不写垃圾）、`sane()` 拒绝
api_error 过半的结果。10 格假数据已隔离（确认未被任何报告引用）。

**② 前提没验证就投算力（job 7194）**
我按"DR-DCI 六集每集 50 题是抽样、扩到 200 题可降误差"写了并行扩样作业。
实际 `dci-bench` **每集就只有 50 题**——那是 benchmark 的全部。`--limit 200` 物理上
拿不到更多。作业还因 `.env` 端口覆盖失效跑出 5 格全 0 的垃圾。已取消并清理。
→ 教训：**提交前先 `wc -l` 数据集**。相应地，AVG 47.3 的 ±14 点不确定性是固有的，
报告里必须标注，不能承诺"重跑能收窄"。

**③ 内存被 tmpfs 吃掉，伪装成两种无关的报错（dci-lite 连续两轮失败）**
dci-lite 的 pi coding-agent 把 bash 工具 stdout 写到 `os.tmpdir()`，而 `/tmp` 是
**tmpfs（占物理内存）且跨作业不清理**。每题 grep 14GB 语料，单个日志到 7.6GB，
739 个残留占了 **101GB 内存**。tmpfs 写失败 → errno **-122** → 工具输出 JSON 腰斩
→ `Unterminated string`（80 个）。**识破线索是截断位置从 25 到 10931 随机分布**——
固定缓冲截断不会长这样。
→ 修复 `TMPDIR=/var/tmp/…`（本地 NVMe）+ 作业结束清理，**这类失败 80 → 0**。
顺手释放的 101GB 内存直接让当时在跑的作业多了 40% 可用内存。

⚠️ 但我一度把 `write ENOBUFS`（116 个）也归到同一个根因上，**这是错的**：
`/tmp` 全程干净的补跑里 ENOBUFS 仍出现 29/92 次。它有独立成因，降并发能压低但压不到 0，
是 dci-lite 剩余 31 题失败的主因，**未解**。

**共同教训**：本周我写的监控脚本里也犯了同一个错——过滤条件只匹配"成功"和"显式报错"，
结果一次静默挂死让循环空转了 13 小时。**写任何守候前先问：如果它现在崩了，
我的过滤条件会输出点什么吗？**

## ⚠️ 本周自查出的两条我写错的结论（已更正）

1. **"search_o1 用 4096 显著提升(p=.0040)"是假的**。当时拿的 2048 基线是 07-06 的运行，
   早于 07-16 的畸形标记 bug 修复——那 +35 全是 bug 修复的收益。换正确基线重测：
   净 −5，p=0.74，**无效果**。差点据此改掉主表配置。
   → 教训：跨版本比较必须核对两侧的**代码版本**，不能只看文件名。
2. **"top-k=3 更好"是噪声**。n=500 上三个数据集全胜看着像信号，n=1500 全部落空，
   2wiki 还反向。→ 教训：小样本上方向一致 ≠ 信号。

两条都源于同一件事：**陈旧/含 bug 的产物留在盘上，早晚会被误用。** 本周末已做全面清理。
