\textbf{Baselines.}
We compare ScaleSeek with baselines under different corpus-access and training settings. (1) \textbf{Direct Output} generates answers using only the backbone LLM's parametric knowledge. (2) \textbf{RAG} follow a standard retrieve-then-generate pipeline, where a fixed set of top-$k$ documents is retrieved once and provided to the LLM as prompt context. (3) \textbf{Search-o1} and \textbf{Search-R1} represent iterative retrieval methods that alternate between reasoning and search. (4) \textbf{DCI} is a prompt-based agent that directly searches the full corpus without a first-stage retriever, while \textbf{DR-DCI} dynamically retrieves documents and adds them to an external workspace during inference. (5)\textbf{GrepSeek} is a training-based agent that searches a static full-corpus environment using grep-style operations. (6) \textbf{RISE-Ext} first constructs a bounded workspace with a retriever and then allows the agent to inspect the retrieved documents using grep and file-reading tools.  We provide implementation details in Appendix~\ref{app:baseline_details}.
